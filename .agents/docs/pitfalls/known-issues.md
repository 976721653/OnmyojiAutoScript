## assets.py 禁止手动修改

`assets.py` 由 `dev_tools/assets_extract.py` 自动生成。手动修改会在下次运行提取工具时被覆盖。如需调整资源定义，通过提取工具的配置来修改。

## 多继承 MRO 顺序

任务类的继承顺序会影响方法解析。组件 Mixin 中可能存在同名方法，继承时靠前的类优先。`GameUi` 通常放在最前（它提供 `ui_goto` 和页面导航链路）。

## .gitignore 覆盖规则

`reference-projects/` 和 `resource/` 使用 `!` 排除规则让 INDEX.md 被追踪。新增子目录时需确保不破坏这条规则。

## 跨平台路径

Windows 路径分隔符为 `\`，但 Python 支持 `/`。项目中统一使用 `/` 作为路径分隔符，确保跨平台兼容性。
