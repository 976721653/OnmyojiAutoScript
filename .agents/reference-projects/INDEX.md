# 参考项目索引

> 外部开源项目索引。Agent 需要在参考项目代码时，先查此索引，再检查本地是否已有 clone，若没有则按源信息拉取。
>
> **注意**：除本 INDEX.md 外，此目录下所有实际代码均已被 gitignore，不会提交到仓库。

| 名称 | 仓库地址 | 描述 | 用途 |
|------|----------|------|------|
| （暂无参考项目） | — | — | — |

## 使用说明

1. Agent 在此表中查找是否有对应项目
2. 检查 `reference-projects/<项目名>/` 是否已有代码
3. 若无，执行 `git clone <仓库地址> reference-projects/<项目名>/`
4. 参考完的代码保留本地，但不会被 git 追踪
